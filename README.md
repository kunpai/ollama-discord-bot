# Ollama + Discord.py

Make sure Ollama is installed. Find it [here](https://ollama.com/)

Also, have a Discord bot token ready. You can get one by creating a new bot on the [Discord Developer Portal](https://discord.com/developers/applications).

Then, run `setup.sh` to install the required dependencies.

```bash
./setup.sh
```

After that, you can run the bot with the following command:

```bash
python3 bot.py
```
